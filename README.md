# Classificador de Nível de Herói

Este desafio de lógica de programação em JavaScript, foi realizado para praticar variáveis, operadores, laços de repetição e estruturas de decisão. No curso "*Formação Lógica de Programação*" - [**(DIO) Digital Innovation One**](https://web.dio.me/)

## Objetivo

Classificar heróis de acordo com a quantidade de XP (experiência) que eles possuem, seguindo a tabela abaixo:

| XP  | Nível |
| --- | --- |
| Menor que 1.000 | Ferro |
| De 1.001 a 2.000 | Bronze |
| De 2.001 a 5.000 | Prata |
| De 5.001 a 8.000 | Ouro |
| De 8.001 a 9.000 | Platina Diamante |
| De 9.001 a 10.000 | Imortal |
| Maior ou igual a 10.900 | Lendário Radiante |

## Recursos utilizados

- Variáveis
- Operadores
- Laço de repetição (`for`)
- Estrutura de decisão (`if / else if`)

## Como rodar

1. Tenha o Node.js instalado.
2. Salve o código em um arquivo chamado `heroi.js`.
3. No terminal, execute:

```
node heroi.js
```

## Exemplo de saída

```
O heroi de nome Fulano está no nível de Ferro
O heroi de nome Ciclano está no nível de Bronze
O heroi de nome Beltrano está no nível de Prata
```

## Observação

Resolvi realizar uma revisão em lógica. Estudar nunca é demais, então este desafio faz parte da jornada de revisões.

Enfim, tomei a liberdade de inserir mais níveis dessa forma, para o código não quebrar, foi criado um nível chamado "Sem classificação" para cobrir esse intervalo.
